# Теплее · Итоги созвона 05.08.2026 и проверка данными

Отчёт по кофейне «Теплее» (Лыткарино): что показали первичные данные кассы yTimes
за 10 месяцев — и что это меняет.

**Сайт:** https://mrdmitrydouble.github.io/teplee-report/

## Что это

Статическая одностраничная публикация. Никакого бэкенда, никакой аналитики,
никаких внешних запросов: все шрифты, скрипты и изображения лежат в репозитории
и отдаются с того же домена.

Страница закрыта от поисковых систем (`<meta name="robots" content="noindex, nofollow">`) —
она рассчитана на доступ по прямой ссылке.

## Структура

```
index.html                     разметка + вся вёрстка отчёта
assets/
  dc-runtime.js                рантайм рендеринга (декларативные компоненты)
  vendor/
    react.production.min.js    React 18.3.1 (локальная копия)
    react-dom.production.min.js
  fonts/                       Golos Text, Playfair Display, JetBrains Mono (woff2, по подмножествам)
  img/paper-texture.png        фоновая текстура бумаги
.nojekyll                      отключает обработку Jekyll на GitHub Pages
```

## Как это собрано

Исходник — самораспаковывающийся HTML-артефакт (~726 КБ), в котором все ресурсы
лежали внутри одного файла в base64+gzip и разворачивались в `blob:`-ссылки
скриптом при загрузке. Для веба он распакован в обычный статический сайт:

- ресурсы вынесены в отдельные файлы с человекочитаемыми именами и кэшируются
  браузером и CDN GitHub Pages;
- React грузится локальными копиями (карта `window.__resources`), а не с unpkg —
  сайт не зависит от внешних CDN;
- убран этап «Unpacking…» перед первым кадром;
- добавлены `lang="ru"`, описание, Open Graph и favicon.
