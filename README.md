# Теплее · Итоги созвона 05.08.2026 и проверка данными

Отчёт по кофейне «Теплее» (Лыткарино): что показали первичные данные кассы yTimes
за 10 месяцев — и что это меняет.

**Сайт:** https://mrdmitrydouble.github.io/teplee-report/

## Что это

Статическая одностраничная публикация. Никакого бэкенда, никакой аналитики,
никаких внешних запросов: все шрифты, скрипты и изображения лежат в репозитории
и отдаются с того же домена.

Страница закрыта от поисковых систем (`<meta name="robots" content="noindex, nofollow">`) —
она рассчитана на доступ по прямой ссылке.

## Структура

```
index.html                       разметка и вся вёрстка отчёта
404.html                         страница «не найдено» в оформлении отчёта
assets/
  dc-runtime.js                  рантайм рендеринга (декларативные компоненты)
  vendor/react*.production.min.js  React 18.3.1 — локальные копии, не CDN
  fonts/                         Golos Text, Playfair Display, JetBrains Mono
                                 (woff2, по подмножествам; greek и vietnamese
                                 не выгружаются — в тексте таких символов нет)
  img/paper-texture.png          фоновая текстура бумаги
  img/og-cover.jpg               превью ссылки в мессенджерах (1200×630)
tools/build.py                   сборка сайта из исходного HTML-артефакта
tools/make_og.py                 отрисовка og-cover.jpg
.nojekyll                        отключает обработку Jekyll на GitHub Pages
```

## Как это собрано

Исходник — самораспаковывающийся HTML-артефакт (~726 КБ), в котором все ресурсы
лежали внутри одного файла в base64+gzip и разворачивались в `blob:`-ссылки
скриптом при загрузке. Для веба он распакован в обычный статический сайт:

- ресурсы вынесены в отдельные файлы с человекочитаемыми именами — их кэширует
  и браузер, и CDN GitHub Pages;
- React грузится локальными копиями (карта `window.__resources`), а не с unpkg —
  сайт не зависит от внешних CDN;
- убран этап «Unpacking…» перед первым кадром;
- сняты мёртвые `preconnect` на Google Fonts: шрифты локальные, а лишний запрос
  к Google со страницы с клиентскими цифрами не нужен;
- критические шрифты первого экрана в `preload`;
- добавлены `lang="ru"`, описание, canonical, Open Graph с картинкой и favicon.

### Доработки под чтение с телефона

Девять графиков и таблиц шире экрана телефона и прокручиваются вбок. К ним добавлено:

- тень у края, которая гаснет, когда блок домотан до конца, — видно, что он двигается;
- подсказка «листайте вбок →» в подписи к рисунку, появляется только там, где блок
  реально не помещается;
- `overscroll-behavior-x: contain` — свайп по графику больше не уводит со страницы
  жестом «назад»;
- `tabindex`, `role` и `aria-label` — до правой половины графика можно добраться
  с клавиатуры и услышать её в скринридере;
- видимый фокус (`:focus-visible`) на всех ссылках, кнопках и прокручиваемых блоках;
- у кнопки «Оглавление» — `aria-expanded`, меню закрывается по Escape.

## Локальная проверка


и открыть http://localhost:8765

## Пересборка

```bash
python3 tools/build.py && python3 tools/make_og.py
```

Пути к исходному артефакту и к папке сайта — константами в начале `tools/build.py`.

## Деплой

GitHub Pages через GitHub Actions (`.github/workflows/pages.yml`). На домен
выкладываются только `index.html`, `404.html`, `.nojekyll` и `assets/` —
сборщик и этот README остаются в репозитории, но не публикуются.

Публикация запускается командой:

```bash
gh workflow run pages.yml -R mrdmitrydouble/teplee-report
```

Триггер `push` в workflow объявлен, но на этом аккаунте GitHub не создаёт по пушу
запусков пользовательских workflow — проверено четырьмя пушами подряд (GitHub видит
`PushEvent`, а `?event=push` возвращает ноль запусков; `workflow_dispatch` и
`schedule` при этом работают). Поэтому после пуша нужно запустить публикацию явно —
командой выше или кнопкой **Run workflow** на вкладке Actions.
